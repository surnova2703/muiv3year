Данные графа разделены на узлы и связи.

Узлы:
- nodes_years: годы
- nodes_publications: публикации
- nodes_journals: журналы
- nodes_persons: авторы/персоны
- nodes_affiliations: аффилиации/организации

Связи:
- edges_year_publication: год -> публикация
- edges_journal_publication: журнал -> публикация
- edges_publication_person: публикация -> автор
- edges_publication_affiliation: публикация -> аффилиация
- edges_person_affiliation: автор -> аффилиация
- edges_publication_topic: публикация -> тема
- edges_publication_keyword: публикация -> ключевое слово
