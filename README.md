# muiv3year

# Инструкция по работе с визуализатором XML графов

## Описание
Веб-приложение для визуализации RDF данных из XML файлов в виде интерактивного графа. Предназначено для анализа семантических связей и структуры данных.

## Структура интерфейса

### Панель управления (верхняя)
- **Загрузка файла**: кнопка выбора XML файла
- **Фильтр связей**: выпадающий список для фильтрации типов связей
- **Показать граф**: кнопка создания/обновления визуализации
- **Экспорт в SVG**: сохранение графа как изображение

### Рабочая область (основная)
- **Левая панель (25%)**: информация о выбранном узле и свойства
- **Центральная область (50%)**: интерактивный граф
- **Правая панель (25%)**: текст статьи из XML

## Пошаговая инструкция

### 1. Подготовка XML файла
Убедитесь, что XML файл содержит RDF структуру с элементами:
```xml
<rdf:Description>
  <rdfs:label>Название термина</rdfs:label>
  <lbm:property rdf:resource="article">
    <lbm:value>Текст статьи</lbm:value>
  </lbm:property>
  <lbm:familyRelation type="related">
    <lbm:value rdf:resource="связанный_термин"/>
  </lbm:familyRelation>
</rdf:Description>
```

### 2. Загрузка данных
1. Нажмите кнопку **"Выберите файл"**
2. Выберите XML файл с расширением `.xml`
3. Данные автоматически обработаются и отобразятся в панелях

### 3. Создание графа
1. После загрузки появится кнопка **"Показать граф"**
2. Нажмите её для создания визуализации
3. Граф отобразится в центральной области

### 4. Взаимодействие с графом
- **Навигация**: используйте мышь для перемещения и масштабирования
- **Выбор узла**: кликните на любой узел для просмотра информации
- **Перемещение**: зажмите и перетаскивайте узлы для изменения расположения

### 5. Фильтрация данных
Используйте выпадающий список для отображения определенных типов связей:
- **"Все связи"**: показать весь граф
- **"Только related"**: связи типа "related"
- **"Только seealso"**: связи типа "seealso"

После изменения фильтра нажмите **"Показать граф"** для обновления.

### 6. Экспорт результатов
Нажмите **"Экспорт в SVG"** для сохранения графа как изображения в формате SVG.

## Интерпретация данных

### Типы узлов
- **Зеленый узел**: центральный термин (основное понятие)
- **Светло-зеленые узлы**: связанные термины

### Типы связей
- **Сплошные стрелки**: связи типа "related"
- **Пунктирные стрелки**: связи типа "seealso"

### Панели информации
- **Левая панель**: 
  - Название и описание выбранного узла
  - Список всех свойств из XML файла
- **Правая панель**: полный текст статьи из элемента `<lbm:property rdf:resource="article">`

## Технические требования

### Браузер
- Современный веб-браузер с поддержкой HTML5
- JavaScript должен быть включен
- Рекомендуется Chrome, Firefox, Safari, Edge

### Файлы
- Формат: XML с RDF структурой
- Кодировка: UTF-8
- Размер: до нескольких МБ (ограничение браузера)

## Структура кода

### HTML
- Семантическая разметка с панелями
- Responsive дизайн с flexbox
- Стилизация через встроенный CSS

### JavaScript
- **Парсинг XML**: использует DOMParser API
- **Визуализация**: библиотека vis-network
- **Обработка событий**: загрузка файла, клики, фильтрация

### Основные функции
```javascript
// Загрузка и парсинг XML
document.getElementById("fileInput").addEventListener("change", ...)

// Создание графа
document.getElementById("showBtn").addEventListener("click", ...)

// Экспорт SVG
document.getElementById("exportBtn").addEventListener("click", ...)
```

## Устранение неполадок

### Граф не отображается
- Проверьте структуру XML файла
- Убедитесь, что присутствуют элементы `lbm:familyRelation`
- Откройте консоль браузера (F12) для просмотра ошибок

### Некорректные данные
- Проверьте кодировку файла (должна быть UTF-8)
- Убедитесь в валидности XML структуры
- Проверьте наличие обязательных элементов RDF

### Низкая производительность
- Уменьшите размер XML файла
- Используйте фильтры для отображения части данных
- Закройте другие вкладки браузера

## Возможности расширения

### Добавление новых типов связей
Модифицировать фильтр в HTML и логику обработки в JavaScript:
```javascript
// Добавить новый option в select
<option value="новый_тип">Новый тип связи</option>

// Обновить логику фильтрации
const edgesToShow = typeFilter === "новый_тип" 
  ? allEdges.filter(e => e.type === "новый_тип")
  : ...
```

### Изменение стилизации
Модифицировать CSS для изменения внешнего вида панелей и элементов управления.

### Расширение парсинга
Добавить обработку дополнительных XML элементов в функции парсинга данных.
