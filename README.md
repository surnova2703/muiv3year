# Визуализация науки на основе метаданных публикаций и журналов

ВКР. Веб-приложение для анализа научных публикаций из OpenAlex — интерактивная карта аффилиаций, граф связей, поиск похожих статей, фасетные фильтры.

## Запуск

Нужны Python 3.9+ и PostgreSQL 14+.

```bash
pip install psycopg2-binary
```

Настрой подключение в `pg_config.py`, восстанови базу из дампа:

```bash
psql -U postgres -d openalex_db -f dump.sql
python openalex_server.py
```

Открыть: http://127.0.0.1:8000

## Структура

```
interface/          — HTML, JS, CSS (фронтенд)
database/           — схема БД и скрипты загрузки
scripts/import.py   — выгрузка публикаций из OpenAlex API
geocoding/          — геокодирование аффилиаций (OpenAlex API + Photon)
openalex_server.py  — HTTP-сервер и REST API
docs/               — презентация и текст защиты
```

## Что внутри

9 994 публикации из OpenAlex, PostgreSQL из 7 таблиц, 80,8% аффилиаций с координатами. Граф рисуется в SVG без библиотек с колоночной раскладкой и пятью режимами отображения. Алгоритм похожих статей считает балл сходства по авторам, темам, ключевым словам, аффилиациям и журналу.
