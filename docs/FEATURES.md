# Что сейчас умеет приложение

Веб-интерфейс: `http://127.0.0.1:8000/VKR1.html`
Запуск сервера: `python openalex_server.py`

---

## Запуск и загрузка данных

При открытии страница сразу показывает 5 демонстрационных статей, затем автоматически
в фоне загружает все данные из PostgreSQL. Никаких кнопок нажимать не нужно.

После загрузки в строке статуса появляется:
```
Загружено из PostgreSQL: 9994 статей.
```

---

## Карта

Режим по умолчанию. Показывает точки на интерактивной карте мира (Plotly Scattergeo).

- **80,8% статей** имеют координаты (8 077 из 9 994)
- Каждая точка — аффилиация автора (учреждение с известными координатами)
- До 5 точек на одну статью
- Клик по точке — открывает детали статьи в правой панели
- При фильтрации карта перестраивается автоматически

---

## Граф статей

Переключается кнопкой **«Граф»**. Доступно 5 режимов отображения:

| Режим | Что показывает |
|---|---|
| **Годы + журналы + статьи + авторы + аффилиации** | Полный граф всех связей (до 70 статей) |
| **Годы + журналы + статьи** | Только структура по времени и изданиям |
| **Статьи + авторы** | Кто с кем соавторствовал |
| **Статьи + аффилиации** | Какие учреждения в каких статьях |
| **Похожие статьи** | Статьи, связанные по общим ключевым словам |

В каждом режиме узлы можно перетаскивать мышью. Клик на узел-статью открывает
её детали в правой панели.

---

## Фильтры

Четыре выпадающих списка в левой панели:

- **Год** — фильтр по году публикации
- **Журнал** — фильтр по изданию
- **Автор** — фильтр по имени автора
- **Аффилиация** — фильтр по учреждению

Фильтры применяются мгновенно. Можно комбинировать несколько одновременно.
Карта и граф обновляются под текущий набор статей.

---

## Список статей

В левой панели отображается список отфильтрованных статей (до 200 за раз).
При большем числе показывается пометка:
```
Показано 200 из 3847. Используйте фильтры.
```

Клик на статью в списке — выбирает её и открывает детали.

---

## Детали статьи

Правая панель. При выборе любой статьи (клик на карте, в графе или в списке):

- Название, год, журнал
- Список авторов
- Аффилиации
- Темы и ключевые слова
- **Аннотация** — загружается отдельным запросом к серверу
- **DOI** — ссылка на оригинальную статью

---

## Похожие статьи

Под деталями статьи — блок **«Похожие статьи»** с ранжированным списком
материалов, связанных с выбранной по ключевым словам и темам.

---

## Статистика

Четыре счётчика в левой панели обновляются в реальном времени:

| Счётчик | Что считает |
|---|---|
| **В базе** | Всего статей, загруженных из PostgreSQL |
| **На экране** | Статей после применения текущих фильтров |
| **С координатами** | Статей, у которых есть хотя бы одна точка на карте |
| **Связей** | Прочерк (функция отключена из-за нагрузки) |

---

## Импорт собственных данных

Можно загрузить свои статьи из файла:

1. Нажать **«Загрузить файл в базу»** → выбрать файл
2. Нажать **«Импортировать»**
3. Данные добавятся в браузерную базу (IndexedDB)

Поддерживаемые форматы: `.json`, `.csv`

Дополнительные кнопки:
- **«Демо в базу»** — загрузить 5 демонстрационных статей
- **«Экспорт базы»** — скачать все статьи из IndexedDB как JSON
- **«Очистить базу»** — удалить все статьи из IndexedDB

---

## Анализ данных

В нижней части левой панели — раздел **«Анализ данных»**:

- **До обработки** — сырые данные последнего импорта (число записей, первые 3 объекта)
- **После обработки** — что попало в базу (нормализованные статьи, статистика)
- Кнопка **«Скачать анализ»** — экспортирует оба блока в JSON-файл

## Серверные скрипты (запускаются вручную)

| Скрипт | Что делает |
|---|---|
| `python openalex_server.py` | Запускает локальный сервер на порту 8000 |
| `python build_separate_databases.py` | Перезагружает все данные из `article_data.json` в PostgreSQL |
| `python fetch_geo.py` | Дополняет координаты через OpenAlex API (для institution_id) |
| `python fetch_geo_nominatim.py` | Геокодирует сырые строки аффилиаций через Photon |
| `python import.py` | Скачивает свежие статьи из OpenAlex API → `article_data.json` |
| `python setup_pg_database.py` | Пересоздаёт таблицы в PostgreSQL из `db.sql` |
